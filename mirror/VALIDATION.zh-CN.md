# E610 多系统 r4 验证说明

本轮按用户指定镜像库中的现有 Linux ISO 补齐统一安装入口。对 52 张 Linux ISO 只读提取启动内核和 ixgbe 模块，逐一核对五个 E610 PCI 设备 ID、内核版本及统一包支持项。逐镜像结果见 `MIRROR-COVERAGE.json`；这是启动文件核对，不表示重新完成了 52 次系统安装。

Debian 10.11 复用 ISO Kit r1 已发布的精确内核模块及证书，核对原 ISO、模块和证书 SHA-256，重新完成真实内核加载/卸载和离线安装测试。安装测试禁用网络、移除编译器，覆盖预检查、重复安装、回退、原文件保留、损坏备份拒绝，以及 initramfs 生成失败后的自动恢复。此历史模块要求关闭 Secure Boot。

Ubuntu 25.04 和 26.04 使用镜像中原有内核及模块验证原生 E610 支持，并执行模块加载/卸载测试；不注入外部驱动。Ubuntu 26.04 桌面版与服务器版分别核对镜像来源和原生模块。

原 r3 的 90 个系统/内核组合以完整原包嵌套保留，模块、证书、安装器及回退状态继续由原安装入口处理。r3 的原始验证记录保存在 `baseline/` 中。

最终产物还需经过实际只读 KVM 数据 ISO、tar.gz、.run 入口验证，并检查旧包的备份保留和回退。最终机器可读结果与日志作为独立附件发布，全部通过后才发布为最新版。

本轮没有 E610 实卡，不能替代链路、吞吐、PTP、SR-IOV 或长期稳定性测试。RHEL 10 和 Oracle Linux/UEK 不在指定镜像库中，因此本轮不宣称已适配；其他架构、清单外更新内核、Windows 及内存测试镜像也不在本包验证范围。
