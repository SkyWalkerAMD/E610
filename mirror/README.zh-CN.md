# E610 镜像库覆盖补齐 r4

本轮范围以用户提供的镜像服务器现有 Linux ISO 为准。镜像库没有 RHEL 10 或 Oracle Linux/UEK，不把兼容发行版的结果冒充这两类系统的验证。

在 r3 的 90 个系统/内核组合基础上，补齐 Debian 10.11 的 `4.19.0-18-amd64` 离线安装入口，并检查 Ubuntu 25.04 的 `6.14.0-15-generic`、Ubuntu 26.04 桌面版和服务器版的 `7.0.0-14-generic` 原生 E610 支持。

构建和验证脚本只在独立工作目录、临时容器和无目标磁盘的虚拟机中运行，不修改部署服务器的网络、内核或原 ISO。发布包继续提供 tar.gz、.run、KVM 驱动数据 ISO、中文说明及校验文件。
