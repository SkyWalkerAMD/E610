# E610 多系统 r3 验证说明

精确系统、内核、原介质来源、驱动和证书校验值见 `manifest.json`。包内 `evidence/` 保存本次逐项日志；`baseline/evidence/` 保留原 r2 的记录。

新增 Ubuntu 20.04 初始版至 20.04.6、Debian 11.11、AlmaLinux 8.10 / 9.0–9.8 / 10.0–10.2、Rocky 10.0–10.2 使用原安装介质或官方 kickstart 软件仓库中的默认内核。Ubuntu 同时覆盖镜像携带的 GA / HWE 内核；没有用仓库的最新更新内核替代安装镜像内核。

每个新增组合先检查官方 ixgbe 模块是否包含五个 E610 PCI 设备 ID。原生支持时不注入额外驱动；否则编译 ixgbe 6.4.5，并在对应真实内核的虚拟机中完成三次加载、卸载。新增外部驱动另验证 Secure Boot 开启、MOK 公钥已注册时的签名模块加载，以及未签名模块被拒绝。

Secure Boot 测试预先导入公钥。历史 Ubuntu 内核使用其原安装镜像的签名启动链；Debian 和 EL 内核使用测试用 Ubuntu shim，并额外信任原内核供应商公钥，没有修改或重新签名内核。此测试不能替代现场固件的 MOK 注册交互，也不表示任何新版启动器都默认接受历史内核。安装包不更换目标系统的启动器。

离线安装测试禁用网络并移除编译工具，覆盖预检查、安装、重复安装、完整回退、原有文件保留、损坏备份拒绝，以及启动镜像生成失败后的自动恢复。用户空间使用对应发行版大版本的容器，内核文件来自精确版本；不等于重新安装了每一张历史镜像。

从 ISO Kit r1 导入的历史模块严格核对原发布 SHA-256，复用其已有真实内核加载及手动/PXE 安装重启记录，并重新验证本次离线安装器。RHEL 测试用户空间离线构建自用户提供的原版 DVD；其他导入组合使用对应发行版容器用户空间。导入模块的 Secure Boot 本轮尚未验证，安装器在 Secure Boot 开启或验签强制状态下停止。

原 r2 的 39 个系统/内核组合完整保留原始包、模块、证书和安装器，统一入口继续委派给原安装器，保留已有备份。最终发布前会对实际只读 ISO 中的 .run、tar.gz 入口、系统选择、校验失败、重复安装和回退进行补充测试。

本轮没有 E610 实卡，未验证新增组合的实机链路、吞吐、PTP、SR-IOV 或长期稳定性。现有软件测试通过不代表所有同系列内核都适配。

RHEL 10 尚未取得原版镜像验证。Oracle Linux / UEK、其他发行版和其他架构不在已验证范围。已经发布的 ISO Kit、独立 Ubuntu 包及原 r2 包继续保留，不用新文件覆盖旧 Release 的原始产物。
